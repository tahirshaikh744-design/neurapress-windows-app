## Reporting a Vulnerability

The NEURAPRESS team takes software security and user privacy seriously. Since this application runs locally on client workstations and handles potentially confidential documents, we welcome responsible security disclosures.

If you discover a potential vulnerability or security issue (e.g., Electron context isolation leaks, code injection via malicious PDFs, or local file access bypasses):

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/features/security/vulnerability-reporting) on the repository.
3. Alternatively, email the maintainer directly at **tahirshaikh744@gmail.com** (Tahir Shaikh / Neuron TS Labs) with a detailed description and proof of concept.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal proof of concept (e.g. sample benign PDF trigger) to reproduce the behavior.
- Operating system version (Windows 10, Windows 11, etc.) and application build version.
- Any suggested remediations or mitigations.

### Our Commitment
- We will acknowledge receipt of your report within 48 hours.
- We will investigate and provide an estimated timeline for remediation.
- Once a fix is verified, a patched release will be published and credit will be given to the reporter (unless anonymity is requested).
